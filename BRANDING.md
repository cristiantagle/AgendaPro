## Logo

- `public/tagle-labs-logo.svg`: uso principal (web, README, presentaciones).
- `public/tagle-labs-icon.svg`: favicon, avatar social, badges.

Ambos archivos pueden abrirse en cualquier editor vectorial para generar variantes.

## Colores principales

| Rol           | Hex     | Uso sugerido                  |
| ------------- | ------- | ----------------------------- |
| Fondo oscuro  | `#0F172A` | Fondos, botones principales  |
| Gradiente deep| `#1D2A4A` | Fondos secundarios           |
| Acento        | `#F97316` | Íconos, CTA, gráficos        |
| Texto claro   | `#E2E8F0` | Titulares sobre fondo dark   |
| Texto suave   | `#CBD5F5` | Subtítulos y links secundarios |

## Tipografías sugeridas

- Primaria: **Inter** (weights 400/600).  
- Alternativas compatibles: `Segoe UI`, `Work Sans`, `Space Grotesk`.

## Tono visual

1. Bloques geométricos que evoquen integraciones y tableros.
2. Fotografía: oficinas reales, notebooks, equipos colaborando.
3. Ilustraciones: líneas delgadas + acentos naranjos.

## Uso recomendado

- Añadir el logotipo en la cabecera del dashboard y en la web pública.
- Personalizar correos transaccionales con la firma *Cristian Tagle · Founder, Tagle Labs*.
